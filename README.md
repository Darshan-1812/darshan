# ✨ About

This project reimagines the traditional developer portfolio as a physical notebook.

Instead of navigating ordinary webpages, visitors experience smooth cinematic camera movements, handwritten typography, realistic page interactions, and carefully crafted animations that make the portfolio feel alive.

Every interaction has been designed to create an immersive storytelling experience while maintaining high performance across desktop and mobile devices.

# 🔒 Code Protection

This project includes multiple client-side safeguards intended to discourage casual inspection and unauthorized copying.

Features include:

- Disabled context menu
- Developer shortcut interception
- DevTools detection logic
- Production minification
- Single-file bundled deployment
- Source code optimization

> **Note:** Client-side measures cannot completely prevent access to code that runs in a user's browser. They primarily increase the effort required for casual inspection.
